First, make your run readable

We pull your GPS track straight from your public activity — no login, no app to install. For that to work, these settings must be Everyone. Takes 30 seconds.

Profile Page → Everyone

  1. Strava → Settings → Privacy Controls
  2. Open Profile Page
  3. Choose Everyone

Flyby → Everyone

  1. Same Privacy Controls screen
  2. Open Flyby
  3. Choose Everyone

The activity itself → Everyone

  1. Open the run → ⋯ → Edit
  2. Set Who can see to Everyone
I’ve set all three to Everyone → Continue

Submit your run

Paste the link to your public Strava activity. In the app: open the run → Share → Copy Link.

Works with app share links (strava.app.link/…) and normal activity links.
